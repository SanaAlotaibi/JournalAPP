# Journali 📔

*Your thoughts, your story.*

Journali is a simple journaling app for iPhone, built with SwiftUI. You can write down your daily thoughts, bookmark the entries that matter most, and find any entry quickly with search and sorting.

## Features

- Add, edit, and delete journal entries
- Bookmark your favorite entries
- Sort by bookmark or by entry date
- Search by title or content
- Swipe to delete, with a confirmation alert
- Discard-changes alert when closing an entry with unsaved edits
- Entries are saved on the device with SwiftData
- Dark design with Liquid Glass

## Built With

- Swift & SwiftUI
- SwiftData
- MVVM architecture

## Project Structure

